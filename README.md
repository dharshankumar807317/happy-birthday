# Happy Birthday 🎂 — a 5-slide greeting
React + Vite + Framer Motion. Slides cross-fade into each other (scroll wheel, swipe, arrow keys, or the chapter menu).
- `npm install && npm run dev` · `npm run build` → `dist/` (Vercel/Netlify configs included)
- Your 12 photos: replace the placeholders in `public/images/` keeping filenames (rose-1…3, sunflower-1…2, lily-1…4, lotus-1…2, pink-1; JPG).
- Flower backgrounds: `public/bg/` · Text, emojis: `src/data.js`
- 5 hidden secrets: 🍫 (01), 🧁 (02), ✦ (03), 🍰 (04), 🎂 (05)
